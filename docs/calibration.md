# 残り時間と見込みの補正

## 残り時間の決め方

- 見込みは Claude が手順ごとに付けた分数です。
- 残り時間 = 作業中の手順の残り ＋ 未着手の手順の見込みの合計。
- 終了予定時刻 = 今の時刻 ＋ 残り時間。
- 回答待ち（🟦）と指示待ち（💤）の間は計測しません。`baro wait` のほか、Claude が AskUserQuestion で聞いている間も自動で回答待ちになります（人の返事を待った時間は手順の実績に入りません）。

## 見込みの補正

Claude の見込みは外れます。baro は終わった手順の実績を `~/.claude/baro/history.jsonl` に残し、実績 ÷ 見込みの倍率で残り時間を補正します。
倍率は 0.05〜3.0 倍の範囲に収め、画面には補正後の残り時間と終了予定時刻だけを出します。

倍率は実績 ÷ 見込みの**幾何平均**（log の平均）です。合計の比にすると、人の返事や機械の処理を待って見込みの何倍にも延びた少数の手順に倍率が引きずられます（ある PC では合計の比が中央値の 2 倍でした）。幾何平均はそうした手順の影響を受けにくく、予測のずれ（|log(予測/実績)|）を最小にする値です。

倍率は 3 段で決めます。

1. 過去の手順全体（直近 100 手順）。記録が少ないうちは 1.0 倍に寄せます。
2. 手順のテーマ（調べる・作る・テスト・文書・git/PR・人の確認 など）ごと。git や PR はすぐ終わり、人の確認は延びる、といった違いを反映します。記録が少ないテーマは全体の倍率に寄せます。
3. 同じ計画で終わった手順。見込みの癖は依頼ごとに違うので、これがいちばん当たります。

補正は何もしなくても効きます。テーマ分けと重みは `~/.claude/baro/calibration.json` に置き、無ければ最初の表示で、その後は `baro end` のたびに、この PC の記録から作り直します。

## 確かめる・詰める

```sh
baro stats                    # 全体の倍率と、延びた手順
baro calibrate --dry-run      # テーマごとの見込みと実績、過去の記録で試した予測のずれ（書き込まない）
baro calibrate --list         # 手順ごとに、どのテーマに入ったか（タブ区切り）
baro calibrate --json         # calibration.json の中身
baro calibrate --reset        # テーマ分けを組み込みのものに戻す
```

テーマ分けを自分の仕事に合わせるには、Claude Code で `/baro-calibration` と打ちます。キーワードを直した候補を過去の記録で比べ、当たるようになるときだけ採用します。手順は [SKILL.md](../src/baro/skills/baro-calibration/SKILL.md)。

計算式は [設計書の「時間の数え方」](DESIGN.md#5-時間の数え方)にあります。
